# Local dimensional video renderer

The film is generated locally with Pillow and FFmpeg. No Runway, external API, model key, or paid video plan is used.

- 11 scenes, one for each conceptual stage from 1D through 11D.
- Persistent luminous seed, restrained dark palette, and consistent composition.
- MP4/H.264 output plus adjacent JSON manifest with SHA-256 provenance.
- Run `python tools/video/inspect_video.py --pretty output.mp4` to verify media metadata.

The output is an artistic visualization, not experimental evidence of higher physical dimensions.
