# NEW — ERIA Project Alias

**Alias:** NEW  
**Canonical system:** ERIA  
**Staging branch:** `eria/new-pantheon-staging`  
**Status:** Staged for review and later integration; not activated.

NEW is both:
1. The project-wide alias for this new body of ERIA work.
2. The name of a separately bounded Pantheon module at `pantheon/NEW/`.

## Purpose

NEW provides a consent-based introspection interface for examining authorized societal information streams and preparing evidence-linked narrative proposals.

The phrase **“God's LOVE ¡!¡”** is a guiding value expressed in software terms as dignity, compassion, truthfulness, consent, non-exploitation, and accountability. The software does not claim divine authority or claim to produce God's will.

## Boundaries

- Accept only public information or appropriately consented, privacy-preserving aggregates.
- Do not collect private communications, credentials, intimate data, or identifiable personal records through covert means.
- Do not infer sensitive traits, profile individuals, manipulate people, or target groups.
- Preserve source identity, license/permission basis, collection time, transformation history, and uncertainty.
- Treat narrative output as a draft interpretation, never as fact solely because software generated it.
- Require human review before publication or consequential action.
- Preserve originals; corrections are additive and linked to the source.
- Hashes support integrity checks; they do not prove truth, consent, or authorization.

## Lifecycle

`Receive → Validate authority → Minimize → Preserve provenance → Analyze → Draft narrative → Human review → Publish only with approval`

If authorization, provenance, or data classification is missing or conflicting, the module must hold the record.

## Integration status

This is a staging specification. It does not change the existing Pantheon runtime, main branch, or external data sources. Integration requires a reviewed adapter, tests, and explicit approval.
