# Ɣơ OPEN + PANTHEON

## Codec bridge and controlled language migration

This package connects the existing `Ɣơ/2:` bit-symbol adapter, the `OG/0` base-5 envelope, nibble-pair encoding, and positive-possibility metadata through shared vectors consumed by Kotlin, JavaScript, and Python.

Canonical source bytes remain immutable. `☆` in `Ɣơ/2:` represents a zero bit; a zero byte is eight `☆` symbols. In `yoro-star-exchange/1`, a whole zero byte is one `☆` token. `·` is a separate semantic possibility record with source digest and byte offset.

PANTHEON preserves `ov` original intent, source hashes, semantic mappings, test evidence, and rollback lineage. Native-language replacements require semantic translation, behavioral parity, independent review, verified scoped authorization, and staged cutover.
