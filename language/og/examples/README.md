# Ɣơ Examples

These files are small, human-readable fixtures for the byte envelope.

- `empty.og`: zero-length byte string.
- `zero-and-one.og`: explicit zero byte followed by byte value one.
- `sample-bytes.og`: illustrative sequence with leading zero and other byte values.

Validate by loading each file and passing its text to `decode()` from `language.og.reference.og_codec`. Examples are inputs only and must not be overwritten by tools.
