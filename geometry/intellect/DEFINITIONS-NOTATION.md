# Mathematical Definitions and Notation

**Purpose:** Establish an unambiguous vocabulary and symbol system before presenting geometric arguments.

## Definition record

For each term, include:

- **Term:** the name of the object or concept.
- **Definition:** necessary and sufficient conditions where appropriate.
- **Domain:** the mathematical setting (for example, Euclidean plane, Euclidean 3-space, affine space, or a specified metric space).
- **Notation:** symbols used and their meaning.
- **Dependencies:** earlier definitions required.
- **Example / non-example:** demonstrate the boundary of the definition.
- **Source or convention:** cite the adopted standard when notation varies.

## Notation conventions

| Concept | Common notation | Meaning / caution |
|---|---|---|
| Point | (P,Q) | A location; not a vector unless explicitly identified |
| Vector | (mathbf v) | A directed quantity in a vector space |
| Line segment | (overline{AB}) | Segment joining points A and B |
| Distance | (d(A,B)) | Depends on the chosen metric |
| Angle | (angle ABC) | Vertex is B |
| Set membership | (x\in S) | x is an element of S |
| Mapping | (f:X\to Y) | Function from X to Y |
| Real numbers | (mathbb R) | The real-number field |
| n-dimensional space | (mathbb R^n) | n-tuples of real coordinates with the usual vector-space structure |

Notation is context-dependent. Define symbols locally when there is any reasonable chance of ambiguity. Do not use the same symbol for unrelated quantities in one derivation.

## Coordinate and unit discipline

State whether coordinates are Cartesian, polar, cylindrical, spherical, homogeneous, or another system. State angle units (degrees or radians), orientation, origin, axis directions, scale, and any metric assumptions.

## Status

A definition fixes meaning within a stated framework. It is not an empirical discovery and does not require experimental confirmation, although a physical model using it may require validation.
