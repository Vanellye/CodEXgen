# ERIA 4D Knowledge Well

The Android Compose screen provides an interactive 4D-inspired knowledge map.

- X/Y/Z are projected spatial coordinates.
- W is a fourth evolving coordinate used to rotate/project the tesseract and express knowledge-time.
- A central shared-foundation mass creates a Newtonian-inspired orbital field.
- The tesseract is a 4D hypercube projected into the 2D screen.
- Nodes represent ERIA Core, Physics, Geometry, Robotics, Telemetry, Research and Governance.
- Drag rotates the W-related projection; controls pause/resume time and adjust gravity strength.

This is an educational visualization, not a general-relativistic solver, a literal four-spatial-dimension simulation, or a hardware controller. Orbital motion uses a softened central-mass approximation for stable visualization. It does not claim to simulate measured physical systems.

The current nodes are authored examples, not an automatic index of every repository file. Future ingestion must preserve source path, commit SHA, timestamp, content digest and synthetic/measured labels. The visualization is read-only and emits no robot commands.
