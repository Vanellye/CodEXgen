## Documentation maintenance

Whenever the project changes:

1. Update the relevant technical note in the same change as the implementation.
2. Add or revise its entry in this index and the relevant folder README.
3. Update the root README if the build path, active platform, major feature set, or project status changes.
4. Label simulations, hypotheses, and fiction clearly; do not present them as measured results.
5. State whether behavior is declared, implemented, tested, or independently verified.
6. Keep geometric reasoning and designs separate from empirical observations and data plots; cross-link rather than merge their roles.

The root README is intentionally brief. This folder is the detailed literature; this index is its navigation layer.
